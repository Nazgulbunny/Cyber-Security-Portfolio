# 🧠 Security Approach

My approach to cybersecurity combines technical investigation with broader system and business thinking.

I generally approach security problems through five questions:

```text
1. What are we protecting?
             ↓
2. What can go wrong?
             ↓
3. How can we prevent it?
             ↓
4. How will we detect and respond to it?
             ↓
5. How do we reduce the impact when controls fail?
```

This means looking beyond individual vulnerabilities and considering the complete system:

**People → Process → Technology → Detection → Response → Recovery**
